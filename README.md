# mcp-ctl tap

Homebrew formulae for [mcp-ctl](https://github.com/erikenz/mcp-ctl): one config file for all your MCP servers.

```bash
brew install erikenz/tap/mcp-ctl
```

`Formula/mcp-ctl.rb` is generated by the mcp-ctl release workflow from the checksums of the release it points at. Do not edit it here; a pull request belongs in [mcp-ctl](https://github.com/erikenz/mcp-ctl/issues).
